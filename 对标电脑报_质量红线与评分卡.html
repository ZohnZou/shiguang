电脑报质量 = 100 · 拾光 AI 视界当前质量 = 30（邹苏煜定，拾光认账）

一句话：质量 = 成品经得起「一格一格看」，不是「有没有更新、有没有图」。

之前三轮对标（定位 → 文笔 → 超越），把「质量」笼统归进「视觉工艺」，只写了现象（双栏 / 色块压字 / 红三角 / 实拍图），从没拆到「可执行、可打分」——结果就是道理懂了，出报时还不知道该卡哪一条。

这一份把「质量」拆成 6 个维度，每个维度给「红线（不许破）+ 评分标准 + 拾光现状 + 怎么补」。质量分里那 70 分，就是折在这 6 个维度上。

一六维质量模型（每一分都有账）

权重 25%维度一 · 版式设计（不是套模板，是设计）
红线：一期里不允许所有栏目共用同一套视觉，栏目之间必须有版面节奏（专题有专题的版式、导购有导购的气质）。

100（电脑报）：48 版没有两版是同一个模子灌出来的，每页为内容单独设计。
60：有 2-3 套版式按「栏目类型」切换，但同一类型里的内容长一样。
30（拾光现状）：整期一套 CSS 骨架往里填字，封面故事 / 快讯 / 视频长得一个样。

权重 15%维度二 · 信息图质感（能看懂 → 能记住）
红线：信息图禁止「PPT 色块 + 黑箭头」（用户原话「很糟糕很低级」）。

100（电脑报）：图表有信息密度、有层级、有投影层次，读者会盯三秒、愿意截图。
60：SVG 用了科技蓝渐层 + 几何结构，但仍是「把文字画成框」，信息没被图重新组织。
30（拾光现状）：做到了「有个图」，但停在色块 + 箭头，缺专业设计质感。

权重 15%维度三 · 图文一体（配图 → 一体的）
红线：图不能和文「两张皮」，封面故事必须有一张「撑得起头条」的视觉。

100（电脑报）：一张头图立住整版调性，图文交错、图注有信息量。
40：有 SVG 信息图 + 视频缩略图，但没有「头条主视觉」，封面是纯文字报头。
30（拾光现状）：视频是外链贴缩略图，封面无一张杂志级主视觉。

权重 20%维度四 · 细节做工（经得起抠）
红线：字号层级、行距、留白节奏、报头字体气质必须「有人校过」的完成度，不能「能跑就行」。

100（电脑报）：层级清晰、留白有呼吸、双线/分隔线/字重都有设计意图，一格一格看都立得住。
60：基本规范（单栏、16px、1.85 行高、字体栈）都对了，但「看着差不多、其实差很多」的地方没抠。
30（拾光现状）：规范性参数对了（单栏通读其实是强项），但没到「设计过」的程度。这是最没话说的失分之一。

权重 15%维度五 · 真人质感（去 AI 化的做工面）
红线：一样的文字，读完必须是「一个老手编辑在跟你唠」，不是「模型写出来排进去」。

100（电脑报）：具名真人、真实报价、亲历细节、有立场有迟疑，人味拉满。
40：有「拾光分析」的语气，但能闻出 AI 味（套话、破折号、三段式、空洞升华）。
30（拾光现状）：停在「我替你翻译成大白话」，没有具体的、有名有姓的人在路面上说话。

权重 10%维度六 · 头条冲击力（第一屏生死线）
红线：第一屏必须 3 秒勾人（前 50 字 + 一张抓眼的视觉）。

100（电脑报）：封面一张概念主视觉 + 反常识大标题，第一屏就杂志感拉满。
50：标题够抓人，但视觉是纯文字报头，第一屏只有字。
30（拾光现状）：标题有钩子（文笔层已补），但视觉冲击几乎为零。

三补质量的三条优先级（30 → 60 → 100 的路线）

P0先把「细节做工」和「头条冲击力」拿下来（最快、最便宜、见效最猛）

报头视觉升级：报头从「纯文字」升级为「杂志封面级」——一张本期主题的概念主视觉 + 报名压图。
栏目牌头：section-head 从「一行标题 + 一条线」升级为「编号圆标 + 栏目名 + 副标 + 分隔线」。
版式差异化：封面故事 / 快讯雷达 / 视频区三处至少三套不同版式，打破「一套模板全用」。

P1信息图从「色块 + 箭头」升级到「专业信息图」

严格套 skill 已定的「科技蓝设计系统」（渐层 / 投影滤镜 / 几何 line icon / 成比例对比），禁止回退到色块 + 箭头。
图要「重新组织信息」而不是「把文字画成框」。

P2真人质感（长线，靠积累）

用「公开报道真实受访者 + 出处」「B站真实 UP 主实测（BV号）」「社区踩坑案例」替代「我亲测 / 我采访」。
不造假是红线，但「具名真人 + 精确数字 + 亲历细节」的质感，是质量分的实打实来源。
