封面故事
cover story

黄仁勋走了一个月，英伟达的"网"开始松了：员工投票要留他，VC 却说钱要绕道

英伟达前 CEO 黄仁勋 2026-11-12 正式辞去总裁、CEO、董事三职，CFO 克雷斯任临时 CEO 已两周。最新三件事拼出"后黄仁勋时代"的真实温度——① 英伟达员工发起挽留行动，内部投票超 97% 支持黄仁勋留任（报道 2026-11-14）；② 多家风险投资人对 TechCrunch 表示，黄仁勋的离去在 AI 初创融资上"炸出一个大洞"，因为英伟达是 AI 生态里最关键的"买单人＋放贷人"——它既给初创公司供货，又通过 Inception 计划、投资乃至"资助初创买自家卡"的方式给整个生态输血（报道 2026-11-13）；③ 黄仁勋本人 11-13 仍公开为"超级智能（superintelligence）"一词辩护——这个词是他为配合美国政界推动 AI 而力推的。（事件 2026-11-12 起 · 报道 2026-11-13~14）
一个创始人的"权力"分两层：一层是经营权（董事会有没有票让你走），一层是生态位（这个行业离了你转不转得动）。黄仁勋在英伟达的第一层权力早就被收了——持股只有 3.6%、没有超级投票权，11 人董事会 10 个独立董事，一纸多数票就把他送走。但第二层权力才刚显露：不是"英伟达离不开黄仁勋"，而是"整个 AI 生态的账本上，黄仁勋这一环是怎么绕的"。

先看懂英伟达在 AI 里的角色，它不只是"卖铲子的"，它是"卖铲子 + 借你钱买铲子 + 再帮你把矿卖出去"的三合一。这一期最值得看的，正是这张"网"——

网的第一层：掏钱给人买卡。 VC 说"大洞"，根子在这。英伟达这几年不光卖芯片，它通过 Inception 孵化计划、英伟达创投（NVentures），以及争议的"资助 AI 初创公司买自家 GPU"（11-13 被 HN/Reddit 扒出的人为制造稀缺指控），成了 AI 创业最上游的"水资源"。一家初创要跑模型，第一笔钱是"有没有卡"，第二笔钱才是"投资人给不给钱"。黄仁勋在位时，这两笔钱常常是绑在一起的——英伟达既是供应商又是早期金主。他一走，这条隐形的"供卡＋供钱"通道会不会断，才是 VC 真正睡不着的地方。

网的第二层：定价权和稀缺叙事。 同期另一条新闻——《出口禁运的英伟达芯片，恰恰是中国最强 AI 模型背后的算力》叠上《英伟达被指故意制造供不应求》，把英伟达的"账货分离"老问题再掀开一层。这不是八卦，是商业模式：英伟达的护城河不只技术，还有"谁拿到卡、谁拿不到、按什么价拿"的分配权。这个分配权，黄仁勋一个人扛了 33 年。换个人，还能不能既对着白宫国会装孙子、又对着全世界客户卡脖子？

网的第三层：向下的"超级智能"叙事。 黄仁勋 11-13 还在为"超级智能"站台，这不是退休老头刷存在感，是在给"AI 该无限烧钱"这个叙事续命——只要"超级智能马上就来"，谷歌微软 Meta 就得继续下订单。他走了，谁来当这个"AI 布道者"？克雷斯是 CFO 出身，擅长的是"算清楚该不该花这笔钱"，不是"画一张让全世界跟着烧钱的大饼"。

所以第 19 期我们讲"创始人≠免死金牌"，这一期要往下钻一层：辞掉一个 CEO 容易，辞掉一张"网"难。 黄仁勋真正的资产从来不是那 3.6% 股权，是他几十年织出来的三样东西——供应链的优先级、生态的信任、以及"AI 该烧钱"的共识。董事会能投票收走他的办公室，收不走这张网；而接棒的人（克雷斯），一个"看账的人"，恰恰是最可能本能地"给这张网收线"的人。



行动落点：别只当"黄仁勋下台"的花边新闻看。真正值得你跟的一条线是——接下来两个月，看英伟达的"生态动作"是收是放：还在持续给初创供卡、投资、开 Inception 吗？还是克雷斯上台先砍"不赚钱的花活"（那些给生态输血但不直接回本的投资）？这个信号，比"谁当正式 CEO"更能告诉你 AI 生态的钱流会不会变向。

拾光立场
shiguang's take

创始人走了，接棒的三种人：技术继承人、看账的、空降兵——你要防的不是"谁接班"，是"接班那一年砍什么"

接第 19 期"创始人权力安全边际"框架——第 19 期讲"怎么判断创始人稳不稳"（持股比例 × 超级投票权），这一期讲"稳不住了、换帅之后怎么接"。英伟达给出了最鲜活的样本：黄仁勋（技术创始人）→ 克雷斯（CFO，财务系）过渡。同期全球科技公司换帅案例可归纳为三种继承模式。（事件 2026-11-12 起 · 报道 2026-11-14）
换帅这件事，难的不是"找个人坐那把椅子"，是"创始人的三种隐性权力，交给谁、怎么过渡"。先拆清创始人手里握着什么——三种：技术方向权（往哪打）、资源配置权（钱和卡给谁）、外部叙事权（跟股东、政府、客户讲什么故事）。三样接得住，才是真接班；只接住一样，公司就会在这某一边漏气。

三种继承模式，本质是"哪一样权力优先交接"：

模式一：技术继承人（创始人 → 内部技术骨干）。 典型如苹果库克接乔布斯前的过渡、或很多硬核公司提拔 CTO/首席科学家。接的是"技术方向权"——这条最稳，因为公司最核心的"产品直觉"没断。但风险也很硬：技术大牛往往不擅长"资源配置"和"资本市场叙事"，容易在产品上继续猛，却在财务纪律、对外沟通上翻车。适用场景：公司正处技术换挡期，最怕的不是钱，是路线走错。

模式二：财务系过渡（创始人 → CFO/临时 CEO）。 英伟达现在就是这条——克雷斯当了十几年 CFO。接的是"资源配置权"——先稳住账、别乱花钱。优点：董事会最喜欢这种，因为 CFO 最懂"哪里在烧钱、哪里能止血"，过渡期公司的财务纪律最稳。风险也最明显：CFO 的本能是"收线"而不是"扩张"——技术路线需要激进投入时（比如押注下一代芯片架构、押注人形机器人这种十年后才回本的事），一个看账的人很可能因为"当年预算不划算"就给砍了。英伟达现在最怕的，恰恰是这个：一个正在被 AMD、谷歌、中国厂商四面围攻的芯片帝国，需要的不是"省钱"，是"继续把最凶的钱砸进最凶的技术"。

模式三：外部空降（创始人 → 空降职业经理人/明星 CEO）。 前面素材库⑱提到过，Polymarket 传言库克被提名做黄仁勋继任者——这就是典型的"空降"想象。接的是"外部叙事权"——请一个名声够响、能立刻稳住股价和华尔街的人来"镇场子"。优点：市场信心恢复最快。风险：空降兵不懂公司内部的技术沉淀和供应链关系的"暗知识"，很可能一上来就砍掉他看不懂、但其实是命根子的业务，或者照搬前公司的药方，水土不服。适用场景：公司大乱、需要外部权威快速止血时。



行动落点：下次你看任何一家创始人离场的科技公司，别只看"接棒的是谁、什么来头"，先问一句——接棒的人是"技术派、财务派还是空降派"？他本能会"扩张"还是"收线"？ 这个判断，比"这个人名气大不大"更能告诉你这家公司未来一两年会变成什么样。落到英伟达：重点盯克雷斯任期内的两个动作——研发预算砍不砍、Inception 这类给生态输血的计划收不收。这两动作决定了英伟达是"稳中求进"还是"守成收缩"。

"接棒比判断更难"：全网都在问"英伟达会不会崩"，但真正该被盯住的是那个"看账的人"会不会砍掉野心

黄仁勋辞任后，市场情绪两极——一边是英伟达员工 97% 投票挽留、一边是 VC 说"黄仁勋走，钱要绕道"。媒体上最热的争论是："英伟达会不会因为失去这位创始人而崩盘？"（报道 2026-11-13~14）
拾光想站一边，说一句可能不太中听、但更接近本质的判断："英伟达会不会崩"这个问题，问错了对象。

一家公司会不会崩，短期看股价情绪，长期看它还能不能继续做对"下一代该押什么"的决定。英伟达的真正风险，从来不是"黄仁勋这个人走了之后没人干活"——它有几万工程师、有 CUDA 生态、有一堆顶尖人才。真正的风险是：接棒的克雷斯（CFO 出身，一个天然"看账的人"），有没有勇气和共识，去押下一个十年才回本的豪赌。

这就是"接棒比判断更难"这句话的意思：判断"该押下一代架构/该押人形机器人/该继续烧钱扩生态"对不对，已经很难；但更难的是——换了个上来就得"对账、省成本、稳住利润"的人之后，公司还有没有那个"敢在不确定的方向上继续下重注"的机制。

历史反复上演一个剧本：创始人（疯狂、有远见、敢烧钱）→ 换上一个"职业经理人/财务型"过渡 → 短期利润上去了、股价稳了，但公司停止了"押注未来"，开始"收割现在"，几年后回头一看，它错过了下一个浪潮。英伟达现在最怕的，就是这个剧本。

所以拾光的立场很明确：别盯着"英伟达股价跌没跌"，盯着"克雷斯任期里，英伟达还在不在做那些'短期不赚钱、但决定十年后'的事"——下一代芯片架构的投入、CUDA 生态的持续输血、物理 AI（机器人）的长线押注。这三个"该烧钱还得烧"的方向，只要还在往前推，英伟达就还是那个英伟达；哪天它们开始被"成本优化"砍掉了，那才是真正该恐慌的信号。

行动落点：把这条判断，当作你自己看"任何一家强公司换帅"的通用框架——问一句"接棒的人，是继续押未来，还是开始割现在？" 这个问题的答案，比"这个人履历多漂亮、股价当天怎么反应"更能预测这家公司的长期走向。落到你自己身上也一样：一个团队/公司/项目换了主事人，你该观察的是"他来了之后，是砍掉了那些短期不赚钱但有未来的东西，还是保住了它们"。

research frontier

Agent 批量筛 1000 条，自动发出去了才发现有一条该拦——"筛不是拍"碰上真·不可逆，边界在哪？

接第 19 期"决策模型=筛不是拍"框架（#82）——那期立了灰区判据：**一条决策该归"筛选"（可放手让 AI 批量做）还是"拍板"（必须人来做），看它的下游有没有"不可逆后果"**。这一期把这把尺子捅到 Agent 自动化题材上去验证：当 AI Agent 开始批量做"筛选→执行"连成串的动作（自动下单、自动发消息、自动改文件、自动删数据），"下游不可逆"这条判据还成不成立？有没有新的灰区？（验证 2026-11-14）
先把尺子立清楚。第 19 期的核心结论是：决策模型的价值不在"它想得快"，在"它把很多原来要人拍板的事，变成了可以批量筛的常规动作"；而"筛"和"拍"的分界线，就是——这个动作做错了，能不能低成本撤回？能撤回的，放心让它筛；撤不回的，就该升级成"目标级"加人审查。

现在把这条尺子放到 Agent 自动化上，它撞出三种情况：

情况一：尺子成立，且尤其重要。 批量筛选本身没问题——让 Agent 从 1000 封邮件里选出"需要回复的"，是典型的可撤回筛选（选错了，人再补一下）。但一旦 Agent 的下游接了不可逆动作，尺子立刻要上移到"目标级"：自动下单（钱出去了、货定了）、自动发消息（发给客户/发到群里，发出即送达、收不回来）、自动改文件/删数据（覆盖了就没了）。这三样的共同点是"发出即生效、覆水难收"。所以判断口诀成立：凡是 Agent 的"批量筛选"后面接了一条"点了就收不回来的动作"，这条就得当"拍板"人来兜底，不能让它纯自动跑到底。

情况二：尺子暴露的第一个新灰区——"批量生成"看似可回退，其实发出即收不回来。 这是这期最值得点破的坑。很多人觉得"生成内容"是安全的（生成错了，删了重来嘛），但放到 Agent 语境里，生成的下游常常是自动发布：Agent 批量生成 500 条文案，自动发到 500 个渠道——单条文案是可以改的，但"发出"这个动作已经完成了，撤回的成本是 500 倍。所以"可撤回"要分两层看：内容可撤回 ≠ 动作可撤回。批量生成的"数量"本身就是一种不可逆——你不可能同时把 500 个已发出的东西逐一收回。

情况三：尺子的第二个边界——"不可逆"要看"影响的乘数"，不是"动作本身"。 同样是"自动发消息"，给内部测试群发错了，一个人能撤回、无伤大雅，可算"半可逆"；给 100 万客户发错了，虽然技术上能撤回，但已经造成的信任损失收不回来。所以真正的判据不该只问"这动作能不能撤"，还要问一句：这个动作接的下游，"影响面 × 不可恢复程度"有多大？ 影响面小 + 可恢复 = 放心筛；影响面大 or 不可恢复 = 上人为审查。



行动落点：如果你正在搭 Agent 自动化（或打算让 Claude Code / Codex 这类工具帮你批处理），落一条可执行的红线——给 Agent 的下游动作分级：纯筛选（读、选、排）= 放手；生成但只存不改不发 = 半放手（抽查）；一旦接"下单 / 外发消息 / 改文件 / 删库" = 加一道"人点确认"的闸。判断口诀就一句："这个动作做错了，我还得回来收拾多远？"收拾得动的才放，收拾不动的就加人。 别让"批量"这个词骗过你——1000 条里错 1 条，撤回成本就是 1000 倍。

前 OpenAI 研究员在中国六大模型里，扒出了英伟达 Blackwell 的"数值指纹"——禁运卡到底流没流进来，这下有了硬证据链

llama.cpp 值得单独拎出来讲，因为它是"AIGC 民主化"里最安静却最硬的一块砖。很多读者天天听说"大模型、大模型"，但默认只能在云端跑、要付费、要联网。llama.cpp 干的事很朴素：用 C++ 把模型推理做到极致高效，让一台没有独立显卡的普通电脑，也能把一个小模型跑起来。

它为什么重要？三个字：本地、免费、可控。

- 本地：模型下载到你自己的机器上，断网也能用，数据不出你的电脑——这对"隐私敏感"、"怕数据外流"的人（医生、律师、处理公司机密的人）是刚需。
- 免费：不用订阅任何云服务，模型是开源的，工具是开源的，跑一次只花你的电费。
- 可控：你想怎么改、怎么部署、用在什么场景，全是你自己说了算，不依赖任何一家公司的 API。

它 1.0 的意义，是"这个地基终于被社区认为足够稳了"。过去它是个"技术宅才能玩转"的黑客工具，现在它稳到可以被当成"本地 AI"的标准底座——很多做"端侧 AI""隐私 AI""离线 AI"的产品，底层都是它。这也对应了你前面看到的趋势：当云端 AI 越来越贵、越来越被政治切分，本地 AI（你自己的电脑、你自己的数据、你自己的模型）会越来越值钱。

先解释为什么"冻结模型 + 外挂记忆"是个聪明的方向。大模型训练完，它的参数就"冻"在那儿了——你想让它记住新东西（比如你的偏好、最近聊过的内容），传统办法是重新训练（微调），又贵又慢，还可能改坏它原本会的东西。Memorilla 的思路反过来了：主模型一个参数都不动，在旁边挂一个小的"记忆模块"，只让这个新模块去学"记什么、什么时候调出来"。

打个比方：主模型是一本已经印好、不能改的厚字典；Memorilla 是塞进去的一个"便签夹"，你在便签夹里写新词条，查的时候它帮你把便签里的相关内容翻出来一起用。这样既保住了原模型的本事，又便宜地加上了"记忆"。

这件事为什么值得看？因为它戳中了当前 AI 一个很痛的短板——"健忘"。你跟 ChatGPT/Claude 聊，聊久了它就忘了你最开始说过什么；跨会话更是"一刀切清空"。如果"外挂记忆模块"这条路走通，意味着未来的 AI 能低成本地记住你——记住你的身份、你的项目、你的偏好，而且不用为每个用户都重训一个大模型（那成本谁也扛不住），只需给每个人配一个小的"记忆便签"。

这也和"Agent"趋势合流：一个能帮你干活的 Agent，最需要的能力就是"记得上下文、记得你交代过什么"。没有记忆的 Agent 是"金鱼"，有记忆的 Agent 才像"老员工"。

行动落点：留给你的一个认知预判——接下来真正好用的 AI 助手，竞争点会从"模型多聪明"转向"它记不记得住你"。你可以从现在起养成一个习惯：用 AI 时，把关键信息（我是谁、我在做什么项目、我的偏好）每次用一句话喂给它当"上下文"，看它能不能接得住；你也会更早体会到"会记住你的 AI"和"金鱼 AI"的差别，从而判断哪家产品值得长期用。

AI Agent 的"地基公司" LangChain 估值飙到 30 亿美元——但更值得你注意的是，大家在抢的到底是"工具"还是"控制权"

先看两派：

"放飞派"：帮你让 agent 更聪明、更自动化、更能自己干（LangChain 本身、各种 agent 框架）。它们赌的是"能自动跑起来的 agent 越来越多"。

"缰绳派"：帮你管住 agent（three.dev 看 agent 怎么失败、Antelog 防 agent 泄漏/毁坏你的数据、Omnigraph 管 agent 的数据）。它们赌的是"agent 越能自己干，就越需要有人盯着、别让它闯祸"。

先讲 AI 眼镜是什么。它是在普通眼镜上装摄像头 + AI，能"看到"你眼前的世界，然后让 AI 帮你识别、翻译、导航、记录。理论上很酷——你抬眼一看菜单，AI 帮你翻译；你一抬手，AI 帮你识别这是哪幅画。但它有个天生的争议点：它戴着摄像头，默默地"看"着你身边的每一个人。

这就是为什么谷歌要主动"藏脸 + 禁人脸识别"。因为如果 AI 眼镜能实时识别你身边每个路人的脸、查他们的信息，那这玩意儿就会变成一个"移动的人脸采集器"——对陌生人隐私的侵犯，比手机摄像头严重得多（手机拍是"明显在拍"，眼镜看是"不知道它在看"）。谷歌这个"自我设限"，本质是在产品还没发布前，先把最危险的那个能力自己砍掉，以避免把一款有潜力的硬件，做成一款"人人喊打"的隐私怪物。

这件事的普适启示是：AI 硬件（眼镜、耳机、穿戴设备）的成败，不取决于"AI 能力多强"，而取决于"它在替你办事时，对旁人的隐私守不守规矩"。 一个"能力超强但让人不安"的 AI 硬件，走不远；一个"能力适中但让人放心"的，才可能普及。

行动落点：如果你未来要用 AI 眼镜这类"盯着现实世界"的硬件，先问它三个隐私问题——① 它是不是默认关闭"人脸识别"这类敏感能力 ② 它拍到的画面存哪、谁看得见 ③ 有没有明显的"正在录制"提示。这三个答案不清不楚的设备，谨慎用。另外，也换位想想：别人戴 AI 眼镜时，你的脸也成了"被看"的对象——对"AI 正在越来越无感地采集现实"这件事保持敏感，是新的数字素养。
